# 🌐 Agora

### The AI Model Marketplace & Deployment Platform

Agora is a **Steam-inspired marketplace for AI models**, designed to make discovering, managing, deploying, and running AI models simple.

Instead of searching through different model repositories, figuring out runtimes, configuring hardware, and manually setting up deployments, Agora brings the experience into one platform.

> **Discover → Review → Library → Deploy → Run**

---

## 🎯 Problem

The current AI model ecosystem is fragmented.

Using an AI model often requires users to:

1. Find a model
2. Understand its requirements
3. Choose an inference runtime
4. Configure hardware
5. Download the model
6. Install dependencies
7. Deploy it
8. Manage the running model

This can be difficult for users who want to experiment with multiple AI models without dealing with infrastructure complexity.

### Agora's goal

Agora provides a unified experience for:

- 🔍 Discovering AI models
- ⭐ Reviewing and rating models
- 📚 Managing a personal model library
- 🚀 Deploying models
- 🖥️ Running models locally
- ☁️ Deploying models to cloud infrastructure
- 👨‍💻 Publishing models as a creator

---

# ✨ Core Features

## 🛒 AI Model Marketplace

Agora provides a marketplace where users can discover AI models.

Each model can contain:

- Model name
- Description
- Category
- Tags
- Creator
- Version
- License
- Model size
- Parameter count
- Runtime
- Source URL
- Thumbnail
- Banner
- Verification status
- Deployment availability

### Supported Categories

- 💬 LLM
- 💻 Coding
- 👁️ Vision
- 🎨 Image Generation
- 🎙️ Audio
- 🔎 Embeddings

# ⭐ Community Reviews

Agora uses a **Steam-inspired community review system**.

Users can:

- Rate models
- Recommend or not recommend models
- Write reviews
- Edit their reviews
- Delete their reviews

Model pages provide:

- ⭐ Overall rating
- 👍 Recommendation percentage
- 📊 Rating distribution
- 💬 Community reviews
- 🔎 Review sorting
